Cetak Lembar Jawaban Komputer (A4)

Cetak skala 100% (jangan “fit to page”), kertas A4, warna hitam penuh. Bagian I dibaca otomatis lewat 4 kotak hitam di sudut dan QR siswa; Bagian II (isian) dan III (essay) diperiksa guru lalu nilainya dimasukkan manual. Siswa mengisi bulatan dengan pensil 2B secara penuh.

Menu Reset Data

Reset ikut terkirim ke database cloud sehingga berlaku di semua perangkat. Ketik RESET untuk konfirmasi. Disarankan unduh cadangan Excel dahulu.

Database Cloud (Apps Script) — Admin

Menu ini hanya tampil untuk akun admin. Tautan deploy sudah tertanam di file ini sehingga semua guru otomatis terhubung tanpa mengisi apa pun.

Reset Password Pengguna — Admin

Untuk guru yang lupa password. Password dikembalikan ke password bawaan, lalu guru bisa login dan menggantinya lewat menu Ganti Password. Perubahan tersimpan di database cloud, jadi berlaku di semua perangkat setelah perangkat guru terhubung internet.

Kode Apps Script (Code.gs)

Kode di bawah adalah satu-satunya kode server yang dibutuhkan, disimpan di dalam file ini. Pasang/perbarui dengan langkah:
  1. Buka script.google.com → buka proyek yang dipakai (atau buat proyek baru).
  2. Hapus isi Code.gs, tempel kode ini (tombol Salin Kode), lalu Simpan.
  3. Deploy → Kelola deployment → ikon pensil → Versi: Versi baru → Deploy (URL tidak berubah). Untuk deploy baru: jenis Aplikasi Web, jalankan sebagai Saya, akses Siapa saja, lalu tempel URL /exec ke konstanta DEFAULT_CLOUD_URL di file ini.
  4. Setujui izin akses Spreadsheet saat diminta. Guru yang mengisi link spreadsheet harus membagikan sheet-nya (Editor) ke akun pemilik script ini.

Spreadsheet Saya (Google Sheets)

Setiap guru memakai spreadsheet sendiri. Cara pakai:
  1. Buat spreadsheet kosong di Google Drive Anda.
  2. Klik Bagikan, tambahkan akun (akun pemilik database — tanyakan admin) sebagai Editor.
  3. Tempel link spreadsheet di atas, klik Simpan Link, lalu Kirim Data.
Yang dikirim: Data Sekolah, Siswa, Nilai, dan Rekap sesuai kelas & mapel Anda. Link tersimpan di akun Anda sehingga ikut ke perangkat lain.
